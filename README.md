# AICE Lite Reversing (PIDCE Lite)

Reverse-engineered BLE protocol and two independent controllers for the RANVOO AICE
Lite neck air conditioner.

- [`PROTOCOL.md`](PROTOCOL.md) — the reverse-engineered BLE protocol spec.
- [`android/`](android/) — native Kotlin/Compose Android controller.
- [`web/`](web/) — Web Bluetooth PWA controller, deployed at
  [pidce.pages.dev](https://pidce.pages.dev).

Tested with the "RANVOO AICE Lite Max 2026" (what a name).
